What does this application do?

This laboratory lets you explore how a robot’s physical design, motion path, and control limits interact. You can analyze a starting robot, inspect its performance, use SVD to discover important design directions, and then change the design while watching the performance update.

You do not need to know SVD or optimization mathematics to get started. A useful way to think about the app is: define a robot → analyze it → see which design changes matter → try a change → compare the result.

1. Define the robotUse the left-hand fields for link lengths, masses and section widths.
2. Define the taskChoose the start/end point, path type and joint torque limits.
3. Analyze performanceClick Analyze path to compute the path, control solution and performance metrics.
4. Explore design directionsClick Compute SVD / hyperspace, preview a direction, then apply a small design move.

First 5-minute tutorial

  1. Leave the default values unchanged. The page opens with a complete two-link example.
  2. Look at the robot and blue task-space path. Green marks the start and red marks the end.
  3. Click a point on the path. The “Selected path point” panel will show the robot configuration, inertia and joint torque demand at that point.
  4. Review the Performance panel. This is the baseline for the current design.
  5. Click “Compute SVD / hyperspace”. The app separates design directions into active directions and redundant/null directions.
  6. Choose a move type. For a first experiment, select a redundant/null direction and keep the default small step.
  7. Use Preview − / Current / Preview + to see how the structure would change before applying anything.
  8. Click “Apply design move”. The app recomputes structure, path/control, performance and SVD before committing the new design.
  9. Compare the Performance change from starting point chart. It shows which metrics increased and decreased relative to your original design.
  10. Use “Undo last design move” if you want to return to the previous structural design.

What do the main terms mean?

  • Design variables: physical quantities the app can change, especially the distributed section widths along the two links.
  • Performance metrics: outputs such as travel time, structural frequencies, mass, smoothness and inertia-related quantities.
  • SVD: Singular Value Decomposition. Here it identifies combinations of design changes that strongly or weakly affect the selected primary performance measures.
  • Active direction (V): a design direction that changes primary performance relatively strongly.
  • Null/redundant direction (N): a local design direction that has little first-order effect on the selected primary performance measures.
  • Secondary objective: a goal such as lower mass or smoother sections that can be pursued inside the redundant design space.
  • Condition number: an indicator of how unevenly sensitive the performance is to different local design directions.

How should a beginner use the move types?

Start with Redundant/null direction. It is the easiest way to see the idea of changing the physical robot while trying to preserve the selected primary performance metrics. Then try an Active SVD direction to see a direction that changes performance more strongly.

The Secondary objective in redundant space option is useful once you are comfortable with the basic workflow. It lets the app search the redundant design freedom for a goal such as lower mass, smoother section profiles, reduced peak width, or improved maneuverability.

What does “Correct nonlinear drift” mean?

Null-space directions are local approximations. A finite design move can drift away from the constant-performance surface. With correction enabled, the application recomputes the nonlinear model and projects the result back toward the protected primary-performance manifold.

Recommended beginner experiment:
Use the default robot → compute SVD → select a null direction → preview ±0.08 → apply +0.08 → compare the performance-change chart → undo → try the opposite direction.

When should I use Global Target Search?

The main laboratory is best for understanding individual design directions and manually exploring the design space. When you know the performance you want—for example, a maximum travel time, a minimum structural frequency, or a mass limit—use Global Target Search. It automatically takes multiple evolving-SVD steps and can also use null-space freedom for secondary objectives.
