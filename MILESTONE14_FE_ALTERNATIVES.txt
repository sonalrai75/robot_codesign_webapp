Key observations:
- Opposite rectangular bending axis makes both frequencies much too high.
- Lumped mass changes frequencies only modestly and worsens f2.
- Timoshenko shear deformation lowers frequencies; it cannot raise the second mode to 248 Hz.
- Mesh refinement from 10 to 20/40 elements has negligible effect, so discretization is not the cause.
- Removing concentrated masses changes the result only slightly.
- Fixing base rotation changes the modal family radically and contradicts the thesis boundary condition.
- A uniform stiffness/E scale would need 0.670 to fit f1 but 1.809 to fit f2, so one material/stiffness scale cannot fix both.

Conclusion: none of these standard alternatives explains the 48/248-Hz pair. The mismatch is modal, not a simple overall stiffness, mass, or mesh-resolution error.
